## 引言
当前步骤索引机制是系统中用于跟踪和反映计划执行进度的核心指标。该机制通过`currentStepIndex`字段动态标识当前正在执行的步骤，为用户提供清晰的执行状态可视化。本文档深入分析该机制的实现原理，包括`updateCurrentStepIndex()`方法的复杂逻辑、字段的自动更新机制以及与前端UI的集成方式。

## 核心机制分析
当前步骤索引机制的核心是`PlanExecutionRecord`类中的`currentStepIndex`字段，该字段动态反映计划执行的当前进度。该机制通过分析`agentExecutionSequence`中各个代理执行记录的状态来确定当前执行的步骤。

**核心组件关系**
- `PlanExecutionRecord`: 计划执行记录主类，包含`currentStepIndex`字段和`updateCurrentStepIndex()`方法
- `AgentExecutionRecord`: 代理执行记录类，包含执行状态信息
- `ExecutionStatus`: 执行状态枚举，定义了IDLE、RUNNING、FINISHED三种状态

该机制确保了系统能够准确地跟踪执行进度，并在前端UI中实时显示当前执行的步骤。

## updateCurrentStepIndex方法逻辑
`updateCurrentStepIndex()`方法是当前步骤索引机制的核心，负责根据执行状态动态更新`currentStepIndex`字段。该方法的执行逻辑如下：

```mermaid
flowchart TD
A["开始更新currentStepIndex"] --> B{"agentExecutionSequence<br/>为空或不存在?"}
B --> |是| C["设置currentStepIndex为0"]
B --> |否| D{"计划已完成<br/>(completed=true)?"}
D --> |是| E["设置currentStepIndex为<br/>最后一步索引"]
D --> |否| F["遍历序列查找状态为<br/>RUNNING的代理执行记录"]
F --> G{"找到RUNNING状态的步骤?"}
G --> |是| H["将currentStepIndex设置为<br/>该步骤的索引"]
G --> |否| I["查找第一个状态不为<br/>FINISHED的步骤"]
I --> J{"找到未完成的步骤?"}
J --> |是| K["将currentStepIndex设置为<br/>该步骤的索引"]
J --> |否| L["所有步骤都已完成<br/>设置currentStepIndex为<br/>最后一步索引"]
C --> M["结束"]
E --> M
H --> M
K --> M
L --> M
```

## 字段自动更新机制
`currentStepIndex`字段在多个关键操作中被自动更新，确保其始终反映最新的执行状态。

### addAgentExecutionRecord方法
当向`agentExecutionSequence`添加新的代理执行记录时，会自动调用`updateCurrentStepIndex()`方法：

```mermaid
sequenceDiagram
participant Client as "客户端"
participant PlanRecord as "PlanExecutionRecord"
participant Update as "updateCurrentStepIndex"
Client->>PlanRecord : addAgentExecutionRecord(record)
activate PlanRecord
PlanRecord->>PlanRecord : 将记录添加到agentExecutionSequence
PlanRecord->>Update : 调用updateCurrentStepIndex()
activate Update
Update->>Update : 检查执行序列状态
Update->>Update : 更新currentStepIndex
deactivate Update
PlanRecord-->>Client : 操作完成
deactivate PlanRecord
```

## 状态转换流程图
以下是完整的状态转换流程，展示了`updateCurrentStepIndex()`方法的决策过程：

```mermaid
flowchart TD
Start["开始"] --> CheckEmpty{"agentExecutionSequence<br/>为空或不存在?"}
CheckEmpty --> |是| SetToZero["currentStepIndex = 0"]
CheckEmpty --> |否| CheckCompleted{"completed == true?"}
CheckCompleted --> |是| SetToLast["currentStepIndex =<br/>序列长度-1"]
CheckCompleted --> |否| FindRunning["遍历序列查找<br/>RUNNING状态的步骤"]
FindRunning --> HasRunning{"找到RUNNING状态的步骤?"}
HasRunning --> |是| SetToRunning["currentStepIndex =<br/>RUNNING步骤索引"]
HasRunning --> |否| FindFirstUnfinished["查找第一个<br/>非FINISHED状态的步骤"]
FindFirstUnfinished --> HasUnfinished{"找到未完成的步骤?"}
HasUnfinished --> |是| SetToUnfinished["currentStepIndex =<br/>未完成步骤索引"]
HasUnfinished --> |否| SetToLastFinal["currentStepIndex =<br/>序列长度-1"]
SetToZero --> End["结束"]
SetToLast --> End
SetToRunning --> End
SetToUnfinished --> End
SetToLastFinal --> End
```

## 结论
当前步骤索引机制通过`currentStepIndex`字段和`updateCurrentStepIndex()`方法的协同工作，实现了对计划执行进度的精确跟踪。该机制具有以下特点：

1. **智能状态判断**：通过多级条件判断，准确识别当前执行的步骤
2. **自动更新**：在关键操作（添加记录、设置序列、完成计划）时自动更新索引
3. **前端集成**：与UI组件紧密集成，提供直观的执行进度显示
4. **状态完整性**：覆盖所有可能的执行状态，包括空序列、已完成、运行中和待执行等场景

该机制确保了系统能够准确反映执行进度，为用户提供清晰的执行状态可视化，是整个计划执行系统的重要组成部分。
