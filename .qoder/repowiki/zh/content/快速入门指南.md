## 简介

JManus（现称Lynxe）是阿里巴巴开发的Java实现的多智能体系统，专为处理需要一定确定性的探索性任务而设计。该系统可用于快速从海量数据集中查找数据并将其转换为数据库中的单行记录，或分析日志并发出警报。本快速入门指南将引导您完成从环境准备到首次成功执行AI代理任务的全过程。

## 环境准备

在开始使用JManus之前，您需要准备以下环境和工具：

### Java环境
JManus需要Java 17或更高版本。您可以通过以下命令验证Java版本：
```bash
java -version
```

### Node.js环境
前端UI构建需要Node.js 16或更高版本。您可以通过以下命令验证Node.js版本：
```bash
node --version
```

### 构建工具
JManus使用Maven作为构建工具，您需要安装Maven。同时，项目提供了Makefile来简化构建和部署过程。

### AI模型提供商
您需要一个DashScope API密钥（或其他AI模型提供商的API密钥）来运行JManus。您可以在[阿里云控制台](https://bailian.console.aliyun.com/?tab=model#/api-key)获取免费的API密钥。

## 启动方式

JManus提供了多种启动方式，您可以根据需要选择最适合的方式。

### 方式1：使用Docker容器化部署（推荐用于生产环境）
```bash
# 拉取最新的Lynxe Docker镜像
docker pull ghcr.io/spring-ai-alibaba/lynxe:v4.7.0

# 运行容器
docker run -d \
  --name lynxe \
  -p 18080:18080 \
  ghcr.io/spring-ai-alibaba/lynxe:v4.7.0
```

**高级Docker配置**：
```bash
# 创建数据持久化目录
mkdir -p ./lynxe-data

# 使用卷挂载运行
docker run -d \
  --name lynxe \
  -p 18080:18080 \
  -v $(pwd)/lynxe-data:/app/data \
  ghcr.io/spring-ai-alibaba/lynxe:v4.7.0
```

### 方式2：通过Makefile构建和启动
```bash
# 构建并运行Docker容器
make docker-build-run

# 或者分别执行
make docker-build
make docker-run
```

### 方式3：直接运行Spring Boot应用
```bash
# 对于类Unix系统（macOS, Linux）
../mvnw spring-boot:run

# 对于Windows系统
../mvnw.cmd spring-boot:run
```

## 前端UI构建与启动

JManus的前端UI使用Vue3构建，您可以通过以下步骤构建和启动前端UI。

### 构建前端UI
```bash

make ui-build

# 或者直接在ui-vue3目录下执行
cd ui-vue3

pnpm run build
```

```bash
# 启动UI开发服务器
make ui-run

# 或者直接在ui-vue3目录下执行
cd ui-vue3
pnpm install
pnpm run dev
```


## 初始配置建议

为了确保JManus能够正常运行，建议您进行以下初始配置。

### 数据库配置
JManus支持H2（默认）、MySQL和PostgreSQL数据库。您可以通过修改`application.yml`文件来配置数据库连接。

**使用MySQL/PostgreSQL**：
1. 在`src/main/resources/application-mysql.yml`或`application-postgres.yml`中更新数据库配置：
```yaml
spring:
  datasource:
    url: your_url
    username: your_username
    password: your_password
  jpa:
    database-platform: org.hibernate.dialect.MySQLDialect/PostgreSQLDialect
```

2. 在`src/main/resources/application.yml`中激活MySQL/PostgreSQL配置文件：
```yaml
spring:
  profiles:
    active: mysql/postgres
```

### AI模型配置
在`application.yml`文件中，您可以配置AI模型提供商的相关参数。默认情况下，JManus使用DashScope API，您可以通过设置环境变量来使用其他AI模型提供商。

## 常见问题与解决方案

本节列出了一些常见的初始化问题及其解决方案。

### 端口冲突
如果18080端口已被占用，您可以通过以下方式解决：
```bash
# 查看端口占用情况
netstat -an | grep 18080

# 停止占用端口的进程
kill -9 <PID>

# 或者使用其他端口启动
docker run -d \
  --name lynxe \
  -p 18081:18080 \
  ghcr.io/spring-ai-alibaba/lynxe:v4.7.0
```

### 依赖缺失
如果遇到依赖缺失问题，请确保您已经安装了所有必要的依赖：
```bash
# 安装项目依赖
mvn clean install

# 应用代码格式化标准
mvn spotless:apply
```

### 配置错误
如果遇到配置错误，请检查`application.yml`文件中的配置是否正确，特别是数据库连接和AI模型提供商的配置。
